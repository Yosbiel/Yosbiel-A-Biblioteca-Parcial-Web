# Biblioteca Digital - Primer Parcial

**Asignatura:** Programación Web
**Estudiante:** Yosbiel Alejandro Díaz Cala
**Año:** 3er Año de Ingeniería Informática

## Descripción
Aplicación web de una sola página (SPA) para gestionar una biblioteca digital. Permite prestar y devolver libros, agregar/editar libros, ver un resumen de estadísticas y ajustar el tema (claro/oscuro). Los datos se guardan en el navegador con `localStorage`.

## Tecnologías
- HTML5 semántico
- CSS3 (Grid, Flexbox, animaciones, responsive)
- JavaScript (DOM, eventos, localStorage)
